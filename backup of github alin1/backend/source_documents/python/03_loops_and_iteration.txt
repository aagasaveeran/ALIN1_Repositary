Chapter 3: Loops – Repeating Actions
Welcome to the World of Repetition! Imagine you need to print your name 100 times. You could write the print() command 100 times, but that would be exhausting. In Python, we use Loops to repeat tasks efficiently.
There are two main types of loops we will master:
1. For Loop: Best when you know exactly how many times you want to repeat something.
2. While Loop: Best when you want to repeat something as long as a condition is true.
3.1 The for Loop
The for loop is like a counter. You tell it where to start and where to stop, and it handles the counting for you.
Basic Syntax: The keyword range() is essential here.
• range(5) means counting from 0 to 4 (5 numbers total).
• Important: Python counts start at 0 by default.
Code Example: Printing a Name 5 Times
for i in range(5):
    print("Vandhaan Suttaan Ponaan Repeat-uh ")
• Output: The text "Vandhaan Suttaan Ponaan Repeat-uh " appears 5 times.
3.2 Mastering range()
The range() function is very flexible. You can give it a specific start and end point.
• range(1, 6): This starts at 1 and stops before 6 (so it prints 1, 2, 3, 4, 5).
Code Example: Printing Numbers 1 to 5
for i in range(1, 6):
    print(i)
3.3 Practical Example: Multiplication Tables
Let's build something useful—a program that prints the "2 Times Table" (e.g., 2 x 1 = 2).
We use the loop variable i to represent the numbers 1 through 10. Inside the print statement, we can do math directly.
Code Example:
for i in range(1, 11):
    print(i, "x 2 =", i * 2)
• How it works:
    ◦ When i is 1, it prints: 1 x 2 = 2
    ◦ When i is 2, it prints: 2 x 2 = 4
    ◦ ...all the way to i is 10.
3.4 The while Loop
The while loop works differently. It keeps running while a specific condition is true. It feels more like an if statement that repeats itself.
The Three Steps of a While Loop:
1. Initialization: Create a variable (e.g., i = 0).
2. Condition: Set the rule (e.g., while i < 5).
3. Increment: Change the variable so the loop eventually stops (e.g., i = i + 1).
Code Example: Printing 1 to 5 with While
i = 0
while i < 5:
    print(i)
    i = i + 1  # Important! If you forget this, the loop runs forever.
3.5 Nested Loops (A Loop Inside a Loop)
You can put one loop inside another! This is great for hierarchical data, like Days inside Weeks.
Analogy: Think of a calendar. You have Week 1, which has Day 1, Day 2, Day 3. Then you have Week 2, which also has Day 1, Day 2, Day 3.
Code Example:
for i in range(1, 3):         # The Outer Loop (Weeks)
    print("Week:", i)
    for j in range(1, 4):     # The Inner Loop (Days)
        print("  Day:", j)
• Output: Week: 1 Day: 1 Day: 2 Day: 3 Week: 2 Day: 1 ...
3.6 Challenge: Factorial Calculator
A classic interview question! A "factorial" (written as 5!) is the result of multiplying a number by all numbers below it (5 * 4 * 3 * 2 * 1 = 120).
Code Example:
i = 5            # The number we want to factorialize
fact = 1         # We start with 1 because multiplying by 0 would ruin it

while i > 0:
    fact = fact * i
    i = i - 1    # Count down: 5, 4, 3, 2, 1
    
print(fact)
